Vice Panels: turn a photo and a caption into bold multi-panel GTA-style cover art with Vice City sunset and neon grades, then export a print-ready PNG. Five collage layouts, four per-pixel colour grades, per-panel drag and zoom, and one-click exports in the standard post sizes — all original artwork, fully offline.

## Run it

```sh
serve app/ with any static file server (a starter serve.ts is included), then open index.html in a browser
```
